# RoastMyHabits

Tuist-based iOS scaffolding for a local-only, neo-brutalist habit tracker that roasts the user about daily progress.

Start here:

```bash
tuist generate --no-open
open RoastMyHabits.xcworkspace
```

Full setup, build, and test commands live in [docs/getting-started.md](/Users/luca/symphony-workspaces/COD-8/docs/getting-started.md).
